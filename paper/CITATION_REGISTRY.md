# Citation Registry

This registry is the single source of truth for manuscript citations during drafting.

## Numbering policy

- Each source receives a stable citation ID (CIT-###).
- The manuscript's current IEEE bracket number is recorded separately.
- IEEE numbers are provisional until the reference list is frozen. If new references are inserted, final manuscript numbering may change; citation IDs must not.
- Every citation used in manuscript prose must appear here.
- Every registry entry must have a verified bibliographic source before final submission.
- A source may support multiple claims, but each use must be traceable in the claim-evidence matrix.

## Required before final submission

1. Run a final literature search for newer or more directly overlapping work.
2. Replace provisional IEEE numbering only after the full reference set is frozen.
3. Verify every DOI, author list, volume/issue/article number, and publication year against the publisher record.
4. Ensure every bibliography entry is cited in the manuscript or deliberately retained as a background reference.
5. Ensure no manuscript citation points to an unregistered source.
